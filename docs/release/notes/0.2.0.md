### 변경 사항
- **추출 엔진 자동 업데이트**: 유튜브가 바뀌어 추출이 안 될 때 앱을 다시 받지 않아도 되도록, 하루에 한 번 yt-dlp 새 버전(stable)을 확인해 자동으로 받습니다. 받은 파일은 공식 체크섬과 실행 검사를 통과해야만 쓰며, 다음 추출부터 적용됩니다.
- 앱 메뉴에 "엔진 업데이트 확인…"과 "앱에 들어 있는 엔진으로 되돌리기"를 추가했습니다.
- 이 기능 때문에 앱이 하루 한 번 GitHub(`api.github.com`, `github.com`)에 접속합니다. 개인 정보는 보내지 않습니다.

0.1.0을 쓰고 있다면 아래 설치 방법대로 새 DMG로 바꿔 주세요(설정은 그대로 유지됩니다).
