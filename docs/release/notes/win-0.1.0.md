Stow의 첫 Windows 버전입니다. 유튜브 링크를 붙여 넣으면 오디오(MP3·WAV·FLAC)나 영상(MP4·최고 화질)으로 저장합니다.

### 기능
- **붙여 넣기만 하면 끝**: 주소를 붙여 넣으면 제목·채널·길이·썸네일을 자동으로 불러옵니다.
- **오디오**: MP3(128/192/320kbps), WAV, FLAC. 제목·아티스트 같은 정보를 함께 넣습니다.
- **영상**: 편집 프로그램에서 바로 열리는 MP4(1080p까지)나 최고 화질(4K까지). 다시 인코딩하지 않습니다. 최고 화질(AV1) 영상을 재생하려면 Microsoft Store의 "AV1 Video Extension"(무료)이 필요할 수 있습니다.
- **대기열과 재생목록**: 여러 개를 차례로 받고, 재생목록은 원하는 영상만 골라 재생목록 이름의 폴더에 모아 저장합니다.
- **안전한 저장**: 같은 이름의 파일이 있으면 덮어쓰지 않고 번호를 붙입니다.
- **Windows다운 화면**: Windows 11 설정 앱 스타일, 라이트·다크 모드, Windows 강조색, 완료 알림.
