Stow의 첫 정식 버전입니다. 오디오에 더해 영상도 받을 수 있습니다.

### 변경 사항
- **영상 다운로드**: "출력"의 **종류**를 **영상**으로 바꾸면 영상 파일로 받습니다. 오디오와 영상 설정은 따로 기억합니다.
  - **MP4**: Premiere·Final Cut 같은 편집 프로그램과 QuickTime에서 바로 열리는 H.264 영상입니다. 해상도는 1080p·720p·480p 중에서 고릅니다(유튜브가 H.264를 1080p까지만 제공합니다).
  - **최고 화질**: 4K 이상까지 가장 높은 화질로 받습니다. 대부분 AV1 코덱의 MP4이며, QuickTime에서는 M3 이후 Mac에서 열립니다. 일부 영상은 WebM·MKV로 받으며 IINA·VLC 같은 플레이어가 필요할 수 있습니다.
  - 고른 해상도가 없는 영상은 그보다 낮은 것 중 가장 높은 해상도로 받습니다. 영상과 오디오를 따로 받아 다시 인코딩하지 않고 한 파일로 합치며, 대기열에 "영상 받는 중 → 오디오 받는 중 → 합치는 중"으로 보여 줍니다.
- **빠른 추출 패널**: 아래 줄 맨 왼쪽에서 오디오·영상을 바꿀 수 있고, 포맷 메뉴에는 고른 종류의 항목만 나옵니다.
- **새 버전을 더 빨리 알림**: 앱을 시작할 때와 켜져 있는 동안 1시간마다 새 버전을 확인합니다. "나중에"로 미룬 업데이트는 하루에 한 번만 다시 묻고, 그사이에는 메뉴 막대 메뉴의 "새 버전 설치…"로 설치할 수 있습니다. 업데이트 창의 변경 사항 목록도 제대로 보이도록 고쳤습니다.
- **완료 알림**: 제목을 "저장 완료"로 바꿨습니다(오디오·영상 공통).
- **이용 안내 변경**: 영상 다운로드를 포함하도록 문구를 고치고, 개발자 면책 문장을 추가했습니다. 업데이트한 뒤 처음 열 때 이용 안내가 한 번 다시 나옵니다.

0.3.0 이후 버전을 쓰고 있다면 앱 메뉴 "업데이트 확인…"이나 자동 업데이트 알림으로 바로 설치할 수 있습니다. 0.2.0 이하라면 아래 설치 방법대로 새 DMG로 바꿔 주세요(설정은 그대로 유지됩니다).
