### 변경 사항
- **대기열과 재생목록**: 영상을 여러 개 넣으면 하나씩 차례로 추출합니다. 재생목록 주소를 넣으면 영상 목록이 나오고, 원하는 영상을 골라 한 번에 담을 수 있습니다(재생목록 이름의 폴더에 저장). 포맷·저장 위치는 대기열에 넣는 순간의 설정을 씁니다. 유튜브가 요청을 막으면 대기열을 잠시 멈추고 "재개"를 띄웁니다.
- **빠른 추출 패널**: 어느 앱에서든 ⌥⌘Y(설정 창에서 변경)를 누르면 작은 패널이 뜹니다. 클립보드에 유튜브 주소가 있으면 채워서 바로 불러오고, Return을 누르면 추출을 시작한 뒤 패널이 닫힙니다.
  - 클립보드는 패널을 열 때, 주소처럼 보일 때만 읽습니다. 유튜브 주소가 아니면 쓰지 않고, 유튜브 외의 곳으로 보내지 않습니다. macOS 15.4 이상에서는 처음 읽을 때 확인창이 뜹니다.
  - 창을 닫아도 Stow는 메뉴 막대에 남아 단축키를 받습니다. 끝내려면 ⌘Q나 메뉴 막대 메뉴의 "Stow 종료"를 쓰세요.
- **앱 자동 업데이트**: 하루에 한 번 새 버전을 확인하고, 있으면 설치할지 묻습니다(앱 메뉴 "업데이트 확인…"으로 바로 확인할 수도 있습니다). 업데이트 파일은 서명을 확인한 뒤 설치합니다. 이 확인도 엔진 업데이트처럼 GitHub(`github.com`, `*.githubusercontent.com`)에 접속하며, 개인 정보는 보내지 않지만 IP 주소와 접속 시각은 GitHub에 남습니다.
- 추출 버튼은 바로 시작될 때 "MP3로 추출"처럼, 다른 영상을 추출하는 중이면 "대기열에 추가"로 표시됩니다.

0.2.0 이하를 쓰고 있다면 이번 한 번은 아래 설치 방법대로 새 DMG로 바꿔 주세요(설정은 그대로 유지됩니다). 0.3.0부터는 다음 버전을 앱 안에서 받을 수 있습니다.
