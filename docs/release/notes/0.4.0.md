### 변경 사항
- **빠른 추출 패널에서 포맷·저장 위치 바꾸기**: 패널 아래의 포맷 칩과 폴더 칩을 누르면 메인 창을 열지 않고 바로 바꿀 수 있습니다.
  - 포맷 칩: MP3(320/192/128kbps), WAV, FLAC
  - 폴더 칩: 최근에 쓴 저장 폴더(최대 5개), "다른 폴더…", "Finder에서 열기". 지워졌거나 연결이 끊긴 폴더는 목록에서 빠집니다.
  - 바꾼 값은 메인 창의 기본 설정에도 그대로 저장됩니다.
- **새 앱 아이콘**: Stow 전용 아이콘을 넣었습니다(청록 바탕에 파형과 보관함).

0.3.0을 쓰고 있다면 앱 메뉴 "업데이트 확인…"이나 자동 업데이트 알림으로 바로 설치할 수 있습니다. 0.2.0 이하라면 아래 설치 방법대로 새 DMG로 바꿔 주세요(설정은 그대로 유지됩니다).
