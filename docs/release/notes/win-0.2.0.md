빠른 추출과 자동 업데이트를 넣었습니다. 이제 Mac 버전과 같은 기능을 씁니다.

### 새 기능
- **어느 앱에서든 빠른 추출**: **Ctrl+Alt+Y**를 누르면 화면 위쪽에 작은 창이 뜹니다. 복사해 둔 유튜브 주소를 자동으로 채우고, Enter를 누르면 대기열에 넣고 닫힙니다. 포맷과 저장 폴더도 그 자리에서 바꿀 수 있습니다.
- **트레이 상주**: 창을 닫아도 작업 표시줄 오른쪽 트레이에 남아 단축키가 계속 동작합니다. 트레이 아이콘을 오른쪽 클릭하면 빠른 추출·업데이트 확인·종료가 있습니다. "Windows를 시작할 때 실행"을 켜면 트레이에서 조용히 시작합니다.
- **앱 자동 업데이트**: 새 버전을 뒤에서 받아 두고, 다시 시작하거나 종료할 때 설치합니다.
- **추출 엔진 자동 업데이트**: 유튜브가 바뀌어 추출이 안 될 때를 대비해 하루에 한 번 새 엔진(yt-dlp)을 확인해 받습니다. 문제가 있으면 앱에 들어 있는 엔진으로 되돌릴 수 있습니다.
- 단축키·트레이·시작 프로그램 설정은 메인 창 아래 "빠른 추출"과 "업데이트"에 있습니다.

### 0.1.0에서 올라올 때
0.1.0에는 자동 업데이트가 없어서 이번 한 번만 새 설치 파일을 받아 실행해 주세요(설정은 그대로 남습니다). 다음 버전부터는 앱이 알아서 업데이트합니다.
