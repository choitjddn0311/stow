### 변경 사항
- **다크 모드 앱 아이콘**: 다크 모드에서는 어두운 바탕에 청록 파형·보관함 아이콘으로 바뀝니다. macOS 26의 색조·투명 아이콘 모양도 지원합니다.
- **오픈소스 라이선스 창**: 앱 메뉴 "Stow → 오픈소스 라이선스…"에서 Stow에 들어 있는 구성 요소(yt-dlp, Python, deno, FFmpeg, LAME, Sparkle, KeyboardShortcuts)의 라이선스 원문을 볼 수 있습니다. FFmpeg·LAME(LGPL)의 원본 소스는 각 버전의 릴리스에 함께 올려 둡니다.
- **화면 다듬기**
  - 영상 정보를 불러오는 동안 자리표시를 보여 줘, 불러온 뒤 화면이 밀리지 않습니다.
  - 네트워크 오류처럼 일시적인 문제로 실패하면 바로 "다시 시도"할 수 있습니다.
  - 대기열 항목을 오른쪽 클릭하면 다시 시도·Finder에서 보기와 함께 제목·주소를 복사할 수 있습니다.
  - 창을 열면 주소란에 바로 붙여 넣을 수 있습니다.
  - 오류 문구를 읽기 쉽게 바꾸고, VoiceOver가 상태와 길이를 더 자연스럽게 읽습니다.

0.3.0 이후 버전을 쓰고 있다면 앱 메뉴 "업데이트 확인…"이나 자동 업데이트 알림으로 바로 설치할 수 있습니다. 0.2.0 이하라면 아래 설치 방법대로 새 DMG로 바꿔 주세요(설정은 그대로 유지됩니다).
