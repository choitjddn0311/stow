# CONTEXT GUIDE — Stow

> 이 프로젝트의 세션 운영 절차.

## 1. 신규 세션 시작
1. `CLAUDE.md`는 자동으로 로드된다.
2. `SESSION_HANDOFF.md`를 읽고 현재 단계와 다음 작업을 확인한다.
3. 설계 정보가 필요하면 `PROJECT.md`에서 해당 장만 읽는다.
4. 이번 작업의 범위와 완료 조건을 먼저 정리한 뒤 시작한다.

복구 확인용 프롬프트:
```text
CLAUDE.md와 docs/development/SESSION_HANDOFF.md를 읽고
현재 상태와 다음 작업을 간단히 정리해줘. 문서에 없는 내용은 추측하지 마.
```

## 2. 작업 중
- 현재 로드맵 단계에 필요한 파일만 읽는다.
- 큰 파일은 필요한 구간만 읽는다.
- 범위나 설계를 바꿔야 하면 사용자에게 먼저 확인한다.
- 구현한 기능은 빌드·테스트로 확인한다.

## 3. 작업 종료
기능 단위 완료, 작업 전환, 세션 종료 전에 `SESSION_HANDOFF.md`를 갱신한다.
- 마지막 업데이트 날짜
- 완료한 작업과 로드맵 진행 상황 표
- 변경한 주요 파일
- 테스트 항목과 결과(확인하지 않은 것은 완료로 표시하지 않음)
- 미해결 문제
- 다음 작업과 완료 조건

설계가 바뀌었다면 `PROJECT.md`도 함께 갱신한다.

## 4. /compact와 /clear
| 상황 | 행동 |
|---|---|
| 같은 단계를 계속 진행 | 세션 유지 |
| 대화가 길어졌지만 맥락이 필요함 | `/compact` |
| 다음 로드맵 단계로 넘어가거나 다른 작업으로 전환 | 핸드오프 갱신 후 `/clear` |
| 세션 종료 | 핸드오프 갱신 후 `/clear` |
| 컨텍스트 사용량 확인 | `/context` |

`/clear` 전에 반드시 `SESSION_HANDOFF.md`가 최신인지 확인한다.

## 5. Git / PR 워크플로

### 원칙
- `main`은 항상 빌드·테스트가 통과하는 상태로 유지한다. **직접 커밋·푸시 금지.** GitHub 브랜치 보호로도 강제한다.
- 예외: 저장소 최초 생성 시의 초기 커밋 1회(문서만).

### 브랜치
- 형식: `<종류>/<짧은-설명>`. 종류는 `feat`, `fix`, `docs`, `chore`, `refactor`, `test`
- 로드맵 단계 작업 예: `feat/step2-engine-bundling`
- 하나의 브랜치 = 하나의 PR = 하나의 기능 단위

### 커밋 메시지
- `<종류>: <요약>` (Conventional Commits). 요약은 한국어 가능
  - 예: `feat: ProcessRunner 추가`, `fix: 취소 시 자식 프로세스 종료`
- 본문에 필요한 경우 이유를 적는다.

### 절차
1. `main` 최신화 → 작업 브랜치 생성
2. 구현, 커밋
3. **로컬 검증**: `SESSION_HANDOFF.md`의 빌드·테스트 명령 실행, 통과 확인
4. 푸시, `gh pr create` (본문은 `.github/pull_request_template.md` 형식, 로컬 검증 결과 포함)
5. **CI 검증**: `build-test` 체크 통과 확인 (`gh pr checks --watch`)
6. **코드 리뷰**: `/code-review` 실행 → 발견 사항 수정 후 다시 3~5
7. 사용자에게 결과 보고(로컬 테스트, CI, 리뷰 결과) → **사용자 승인 후** `gh pr merge --squash --delete-branch`
8. 로컬 `main` 최신화, 작업 브랜치 정리

### 실패 시
- 로컬, CI, 리뷰 중 하나라도 실패하면 병합하지 않는다. 원인을 고치고 같은 브랜치에 커밋을 추가한다.
- CI 실패 원인이 러너 환경 문제(예: Xcode 버전)라면 사용자에게 보고하고 워크플로 수정은 별도 커밋으로 진행한다.

## 6. 문서 관리 원칙
- **PROJECT.md**: 잘 바뀌지 않는 정보(목적, 스택, 구조, 결정, 로드맵 정의)
- **SESSION_HANDOFF.md**: 자주 바뀌는 상태(진행 상황, 다음 작업). 이력은 쌓지 않고 최신 상태로 덮어쓴다.
- **CLAUDE.md**: 짧게 유지한다. 상세 내용은 위 문서로 분리한다.
- 같은 내용을 여러 문서에 반복하지 않고 다른 문서를 참조한다.
